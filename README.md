# Ali Haidar - Professional Developer Portfolio

> **Computer Science Student | Aspiring Software Engineer | Web Developer**  
> *International Islamic University Islamabad (IIUI)*

A modern, high-performance personal portfolio website engineered with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**. Designed with a sleek developer aesthetic, subtle glassmorphism, responsive architecture, and dark mode as default.

🌐 **Live GitHub Repository:** [https://github.com/ali-haidar120/portfolio](https://github.com/ali-haidar120/portfolio)

---

## 🚀 Key Features

- **Dark / Light Mode Toggle:** Default dark obsidian theme with smooth theme transitions and `localStorage` persistence.
- **Dynamic Hero Section:** Animated typewriter title rotation, integrated authentic photo presentation in an IDE window frame, and downloadable CV.
- **Categorized Skills Matrix:** Interactive category filters (Languages, Web Development, Backend & DB, Tools, Competencies) with instant keyword search.
- **Projects Showcase & Modals:**
  - *Learning Management System (LMS)* — Django, Python, Bootstrap, Role-Based Access Control.
  - *Library Management System* — C++, OOP, Persistent File I/O.
  - *Inventory Management System* — Relational DB Design, 3NF Normalization, SQL Queries.
  - Interactive deep-dive modal architecture breakdown for each project.
- **Career & Volunteer Experience:** Timeline highlighting industry web development internship at Kohistan Builders and operations leadership at SENSE Society.
- **Interactive Contact Section:** Form with live client validation, one-click email and phone copying, and celebratory confetti animations.

## 💻 Local Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ali-haidar120/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173/](http://localhost:5173/) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
